# Boom Gate Mechanism

## Principle of Operation

The boom gate uses a **servo-driven crank-slider mechanism** to produce horizontal movement.

The mechanism works in the following sequence:

**Servo Motor → Crank → Connecting Rod → Slider → Barrier Arm**

1. The **servo motor rotates the crank**.
2. The **crank converts rotary motion into linear motion** through the connecting rod.
3. The **connecting rod moves the slider horizontally**.
4. The **slider moves the barrier arm** between the open and closed positions.

The slider is guided by fixed guide plates to keep the movement straight and stable.

The mechanism is designed to provide simple, controlled horizontal movement using a servo motor.
